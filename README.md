## How I work

- **Rules first, tokens last.** Anything programmable (empty fields, date formats, duplicate keys) runs as deterministic rules and never burns a token.
- **Gate by severity.** Errors block submission; Warnings pass with a recorded reason. AI review should inform the gate, not own it.
- **Every model swap runs the fixed test set.** Regressions get attributed to a cause, not shrugging at "the model changed".
